# 标准食材词表复核报告（T2）

范围：`app/assets/data/vocabulary.json`（由 `tools/whilefresh_tools/vocabulary/vocabulary-source.json` 生成）、`tools/whilefresh_tools/vocabulary/ingredient-map.json`、`recipes.json` 的 `canonical` 字段。统计和抽样部分由 `uv run --project tools python -m whilefresh_tools.vocabulary report` 生成（固定随机种子，可复现）；其余为人工记录。

## AI 初稿与人工复核的关系

- 初稿用 `deepseek-flash`（关闭 thinking）生成：21 次按品类 / 主题请求词表，13 次把 965 种菜谱原料写法映射到词表并补充缺项；共 34 次成功请求，约 17.1 万输入 + 4.7 万输出 token（21.9 万）。另有 6 次探针和失败请求（thinking 默认开启，8000 token 全被思考吃掉、没有输出，约 2.6 万 token），合计约 40 次请求、约 25 万 token。
- 初稿共 790 个标准名，人工复核后保留 543 个；初稿存在明显问题：内脏 / 切法 / 品种拆得过细，品类放错，`parent` 方向错误，别名跨项冲突，映射里大量空值。所有修正已直接落在源数据文件中，之后重建不再调用 AI。

## 人工修正清单

粒度与精简（初稿 790 → 543）：
- 304 项被删除或并入（其中 99 项并入保留项的别名，205 项直接删除）：猪牛羊禽内脏和冷门部位（猪大肠头、猪天梯、牛肺、鸭舌、鹅肝等）、冷门蔬果（佛手瓜、儿菜、莲雾、杨桃等）、干制水果（芒果干、榴莲干等）、品种（哈斯牛油果、酥梨、蛇果、金煌芒等并入对应别名）、`速冻X` 系列（速冻南瓜、速冻西兰花等 20 余项并入"速冻蔬菜"）、冷门粮豆（三角豆、斑豆、饭豆等）、重复项（豆腐竹 / 腐竹、鱼豆腐干 / 鱼豆腐等）。
- 过长的别名列表（速冻蔬菜 40 余个、果干、香肠等）裁剪到 10 个以内，避免识别提示词过长。

品类修正（64 处）：
- 豆腐、豆皮、腐竹、豆腐干、豆腐泡从蔬菜移到豆制品；粉丝、红豆、绿豆、黄豆、黑豆、薏米移到主食粮油；海带、紫菜移到水产；酸菜、梅干菜、泡椒、番茄罐头移到加工 / 速食；豆豉移到调料。
- 蚝油、虾酱、鱼露从水产移到调料；蛋黄酱从蛋奶移到调料；芝麻香油、花椒油、辣椒油从主食粮油移到调料；猪油从肉类移到主食粮油；泡打粉、酵母粉、小苏打、各类酒移到其他；牛蛙移到水产。

`parent` 方向与合理性（多处）：
- 去掉不成立的 parent：内脏、骨、血、皮、蹄不挂到猪 / 牛 / 鸡 / 鸭（猪肝不能满足"猪肉"）；干香菇 / 干木耳 / 紫薯 / 彩椒 / 娃娃菜 / 河粉 / 米粉 / 韩式辣酱等不挂到对应鲜品或其他品种；洋葱粉、姜粉、蒜粉不挂到洋葱 / 姜 / 蒜。
- 补上必要的层级：新增"酱油"作为生抽、老抽、蒸鱼豉油的上位（**生抽与老抽保持独立，没有合并**）；新增"醋"下的陈醋、香醋、米醋、白醋；新增"虾"（基围虾、明虾、白虾、青虾、北极甜虾）和"鱼"（草鱼、鲈鱼等 24 种鱼）；新增"葱"下的大葱、小葱（初稿把它们当别名，丢失了"小葱 → 葱"的层级）；挂面、拉面等 → 面条；土豆淀粉等 → 淀粉。
- 把"从整体取出的部分"并入整体而不是做子项（鸡蛋清、蛋黄、蛋液并入鸡蛋）：parent 只表达"有子项可满足父项"，反过来不成立。

别名冲突与错误：
- 酱油原为生抽的别名，已改为独立上位项；"小茴香"原是茴香（蔬菜）的别名，改为独立的调料；"牛油"原是黄油的别名，改为独立项；"沙拉酱"原是蛋黄酱的别名，改为独立项；"豆蔻""哈密瓜""芸豆"等跨项冲突已拆开。
- 初稿合并阶段自动丢弃了 46 个与已有名称或别名冲突的别名、151 个重复条目；其余冲突由校验脚本逐项暴露后人工拆开。

## 存疑条目

- 品类边界：食用油 / 猪油 / 牛油归主食粮油（按需求"粮油"），芝麻香油 / 辣椒油归调料；花生、莲子、枸杞、坚果归其他；酒类归其他（料酒归调料）。如界面颜色希望不同，只改 `category`。
- 备选写法（"A 或 B""A/B"）只取第一个，如"料酒或啤酒 → 料酒""辣香肠或午餐肉 → 香肠"，会漏掉备选项；"葱姜蒜 → 葱 + 姜 + 蒜"这类并列写法是"全部需要"。
- 明显偏差但接受：米酒 → 料酒、酒 → 白酒、冷饭 → 大米、桂圆 → 龙眼（鲜果与干品共用）、酸笋 → 竹笋、日本豆腐 → 豆腐、棉花糖 → 糖果、伏特加 / 金酒虽已独立，其他烈酒（威士忌等）仍是初稿的少量覆盖。
- 凤尾（水煮肉片）→ 莴笋叶、黄花（生汆丸子汤）→ 黄花菜、葱头（山西过油肉）→ 葱：按菜谱上下文判断，未逐一核对原菜谱。
- `parent` 取舍有主观成分：鸡翅、鸡腿、鸡胸肉 → 鸡肉（成立）；整鸡 → 鸡肉；西芹 → 芹菜；青椒 / 尖椒 / 线椒 / 小米辣 → 辣椒；圣女果 → 西红柿；五花肉 / 排骨 / 里脊 → 猪肉。若匹配结果偏宽，优先收紧这些。
- 菜谱原料映射为空的 61 种写法见文末。它们是冰块 / 泛称（"蔬菜""配料"）/ 描述性文字 / 冷门香料或补品（印度黑盐、藏红花、西洋参等）；冷门香料如有需要再补词表。
- 条目最多的是调料 97、蔬菜 96；超市生鲜（水果 42、蛋奶 18、豆制品 10）偏少，识别层遇到词表外商品应落到"未归类"由用户确认。
- 保质期（T3）粒度提醒：`鱼`、`虾`、`肉丸`、`速冻蔬菜`等泛称项是匹配层级用的，参考表建议直接映射到具体子项，泛称项仅作回退。
