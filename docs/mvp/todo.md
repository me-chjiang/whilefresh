## 6. 数据质量与保质期口径

以下是复核任务，不预设所有争议映射都必须更改。修改源数据后按 [开发文档](../development.md) 重建并校验生成物。

- [ ] 复核 `receipt-03-perspective-blur` 的“鲜切面条 → 面条”，确认是否应识别为“鲜面条”（[识别基线](notes/recognition-baseline.md)）。
- [ ] 复核 `order-mall-list-01` 的“藤椒油 → 未归类”，确认“花椒油”映射依据。
- [ ] 修正或明确四份文本样本的来源口径：`text-darkstore-01`、`text-delivery-02`、`text-mall-03` 被判为 order，`text-share-04` 被判为 cart，而标准答案为 text。
- [ ] 复核 FoodKeeper 偏短条目：全谷物常温 60–120 天，鲜面条、内脏、肉末及禽肉冷藏 2 天；区分包装标注与参考值（[参考表复核](notes/shelf-life-review.md)）。
- [ ] 复核未开封 / 成熟度口径：酱油与醋 730 天、整粒香料 1095 天、味噌 365 天、枫糖浆、成熟水果；明确适用条件，避免当成所有状态通用期限。
- [ ] 复核淡奶油冷藏 10 天与国内常温 UHT 产品的差异；补查冬瓜整只 / 切开、鱼类及蛋类近似映射是否需要细分。
- [ ] 评估高频食材参考值缺口：牛奶、韭菜、猪油、火腿 / 香肠、豆腐乳 / 豆皮 / 豆腐干、皮蛋、粉丝 / 米粉、莲藕、莴笋；只纳入有依据的值，其余维持明确的未知或 AI 来源。
- [ ] 复核参考表在购买日期未知时按入库日估算的偏晚风险，明确当前展示与适用边界；同步修正开发文档与实现口径不一致的说明，规则变更需单独确认（`resolveShelfLife`）。
- [ ] 复核当前词表实际存在的宽泛 parent 关系，如五花肉 / 里脊 / 前腿肉 → 猪肉、西芹 → 芹菜、辣椒子类及圣女果 → 西红柿；历史审查提到但已删除的关系不重复修复（[词表复核](notes/vocabulary-review.md)）。
- [ ] 复核干木耳 / 干香菇的上位回退是否误用鲜品期限，以及“芽菜”的歧义；区分匹配层级与保质期回退语义。
- [ ] 复核偏差映射：米酒 → 料酒、酒 → 白酒、冷饭 → 大米、桂圆 → 龙眼、酸笋 → 竹笋、日本豆腐 → 豆腐、棉花糖 → 糖果。
- [ ] 对照原菜谱核实“凤尾 → 莴笋叶”“黄花 → 黄花菜”“葱头 → 葱”的上下文映射。
- [ ] 修正演示种子中茭白、山药等缺少估计天数的问题；保留确实未知时的提示，不虚构天数（`AppModel::seedDemo`）。
