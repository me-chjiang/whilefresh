## 发给试用者的说明（可直接转发）

1. 安装时手机会提示"未知来源"，在设置中允许本次安装即可。
2. 打开后底部有五个入口：冰箱、菜谱、清冰箱（中间红色按钮）、待买、我的。
3. 买菜回来：冰箱页右上角"＋ 入库"，选相册截图、拍小票、粘贴订单文字或手动添加；也可以在购物 App 截图后用系统"分享"发给"趁鲜"。
4. 识别前会提示：图片或文字会发送到 DeepSeek 识别。截图里的收货地址、电话最好先裁掉。识别结果只保存在手机本机。
5. 识别出的商品需要你核对后才会进冰箱；保质期标"估计"的仅供参考，请看实物决定。
6. 想先看看效果：在"我的"打开演示模式，用示例数据体验，不联网、不影响真实数据。

## 已知限制

- 识别服务密钥随安装包下发，试用结束后会作废；请不要转发安装包。
- 保质期参考来自 USDA FoodKeeper，豆制品、腊肉、速冻水饺等常由 AI 估计；参考表起算日在不知道购买日期时用入库日期，可能偏晚。
- 入库确认页可修改入库日期；未经修改时默认当天。
- 粘贴的订单文字在导入记录中显示来源为"分享"。
- 当前源码已在 Android x86_64 模拟器上复验；arm64 真机未实测。
- 模拟器上偶见系统界面无响应弹窗，来自模拟器本身。
