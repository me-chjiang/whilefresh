## T6 识别层（`feat/recognition`）

- 主会话检查：桌面构建与 ctest 6/6（98 个用例）通过；Android x86_64 构建通过；无密钥、无署名；仓库中无真实购物数据。
- 在线验证（1 次，计费）：用户样例长截图，约 11 秒、9.3k token，15 件勾选商品全部识别，生产日期原文全部带出，推荐 / 凑单 / 横幅正确排除。录制只存 `private/recordings/`。
- Sonnet 审查结论：**修改后可合并**。密钥、Authorization、图片 base64、订单文字均未进日志；取消、重试与对象生命周期无竞态；错误映射合理。

| 严重度 | 问题 | 处理 |
| --- | --- | --- |
| 中 | 60 秒"无数据传输"超时在模型生成期间可能误触发，并重试一次造成重复计费 | 已修：空闲 150 秒 + 整体截止 240 秒，超时不重试 |
| 中 | 未设置 `max_tokens`，输出被截断时整次导入失败 | 已修：按文档设上限；截断时返回已完整的部分并标记"可能有遗漏"；另据 T2 发现 `deepseek-flash` 默认开启思考，上限需覆盖思考 |
| 中 | 大图先全尺寸解码，可能超出 Qt 图像分配上限，低内存手机有风险 | 已修：解码时缩小，边切边编码 |
| 中 | Android 缺 qjpeg 插件时报错误导用户 | 已修：启动前检查，确认 APK 打包该插件 |
| 中 | 词表别名可能静默挤掉后面的标准名 | 已修：两遍加载，冲突记警告 |
| 低 | 与正式词表的品类代码对接 | 已修 |
| 低 | 空 `choices`、异常数值、跨批次误去重、SSL 失败被报成无网络、图片内文字注入防护、录制工具可写入仓库 | 已修 |

- 修复后：ctest 7/7（141 个用例）；Android x86_64 构建通过，APK 内含 qjpeg 插件。
- 合并前在线复验（1 次，计费）：正式词表（544 项）+ 用户样例长截图，`max_tokens=131072`、`temperature=0`、思考开启均被接受；约 10 秒、10.8k token；15 件勾选商品（含 1 件赠品）全部识别，**未归类 0**；可见生产日期全部带出；推荐、凑单、横幅、配送费正确排除。验证后恢复为无密钥构建。

| 严重度 | 问题 | 处理 |
| --- | --- | --- |

| 中 | 信号契约注释与实现不符；畸形桥消息被静默丢弃且残留文件；无信号顺序测试 | 已修 |
| 低 | `files/imports/` 无清理，`.part` 孤儿文件 | 已修：启动时清理过期 `.part`；正式文件删除责任交入库流程（T5/T8） |

| 低 | `GetStringChars` 未判空、重复点击、provider 读取无超时、相机 MIME 写死、测试边界缺口 | 已修 |

## T3 保质期参考表（`feat/shelf-life-table`）

- 主会话检查：pytest 122/122；无署名、无密钥；抽查常见食材天数，发现鸡胸肉、鱼、虾仁、玉米、鲜面条冷藏仅 1 天。
- 覆盖：290 / 544 个标准名有参考值，沿 parent 回退后 58.5%，按菜谱用料次数加权 69.8%；豆制品、腊肉、香肠、速冻水饺、皮蛋等无对应条目，交给 AI。初稿用 DeepSeek 7 次请求、约 8.3 万 token。
- Sonnet 审查结论：**修改后可合并**。映射本身基本正确，问题在取值口径。

| 严重度 | 问题 | 处理 |
| --- | --- | --- |
| 高 | 取最短值时 55 个标准名冷藏 ≤ 2 天、11 个常温 ≤ 2 天，按临期规则一入库即"临期"（禽肉、鱼虾、叶菜、鲜面条、玉米等） | 修复中：Min ≤ 2 天且有 Max 时取 Max，`basis` 记录实际字段；不改全局临期阈值 |
| 高 | 过长值：芝麻、午餐肉常温 5 年，酱油 3 年，奶粉 3 年 | 修复中：人工修正（365 / 730 / 730 / 365），`basis` 标 `manual` 并写明原因 |
| 高 | 条目状态不符：土豆、苹果、李子、甜瓜的冷冻值只适用于熟制 / 切片；土豆、芋头不宜冷藏；坚果、面包、果汁常温口径与国内不符；生蚝等冷藏偏长 | 修复中 |
| 中 | 香菜冷藏 14 天、姜常温 2 天、西瓜常温 1 天等与国内口径不符 | 修复中：人工修正 |
| 中 | 干货 / 罐装 / 腌制品经 parent 回退可能静默继承鲜品值（当前无实例） | 修复中：加白名单测试 |
| 中 | 牛奶、西红柿高频但无值 | 修复中：西红柿借用圣女果条目；牛奶留空交给包装日期或 AI |
| 代码 | 无前缀字段回退未按 tips 排除熟制 / 切片 / 不推荐；缺"常温长于冷藏"警告；缺极端值断言 | 修复中 |
