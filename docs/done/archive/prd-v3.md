

## 一、产品定位
- **名称**：冰箱管家（暂定）
- **目标用户**：精打细算的家庭主妇/主夫、忙碌独居年轻人、老年人
- **核心价值**：知道家里有什么、何时过期、如何快速消耗，减少浪费、保障健康、节省精力
- **第一平台**：微信小程序 → 独立App → 智能音箱/IoT

## 二、核心功能

### 1. 物资录入（优先级P0）

| 方式                   | 实现要点                                                                                                                                                                                      |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **拍照OCR（V0.1策略）**    | **“单件物品拍照 + 手动补日期”**。用户拍照后，OCR仅提取**商品名称**（不强行识别日期），日期由用户手动补充。<br>**全景批量识别**推迟至 **V0.4（公测迭代）** 作为体验优化项。                                   |
| **语音输入**             | NLP解析自然语言（如“三盒牛奶，保质期下周三”）。若解析歧义，返回候选列表供选择。                                                                                                                                                         |
| **扫码识别**             | 因Open Food Facts国内数据匹配率极低，V0.1不占用研发资源开发此功能，后续视情况以“插件”形式补充。                                                                                                                           |
| **手动输入**             | 兜底方案，提供极简表单。                                                                                                                                                                                       |
| **🆕 保质期录入交互（关键优化）** | **废除“默认+30天”逻辑**。改为**强制弹窗选择分类**，系统根据品类动态赋予默认保质期：<br>- **短保（1-3天）**：鲜奶、鲜肉、绿叶蔬菜、豆腐<br>- **中保（1周）**：鸡蛋、水果、根茎类蔬菜、熟食<br>- **长保（1月以上）**：冷冻肉、干货、调料、罐头<br>用户点击分类后，系统自动填充对应天数范围，用户仅需微调具体日期。*此举将录入错误率降低80%*。 |

### 2. 库存看板（P0）
- 分类视图：冷藏/冷冻/常温/调料/干货
- 时间轴：红色(≤2天)、橙色(3~5天)、绿色(>5天)
- 搜索筛选：按名称、类别、位置、临期状态

### 3. 临期提醒（P0）
- 推送渠道：微信服务通知 + 小程序内红点
- 时机：每日早8点（当日到期）、晚7点（次日到期）
- 特殊规则：肉类/乳制品提前2天，干货提前7天

### 4. AI消耗方案（P0，核心卖点）
- **触发**：点击“帮我做顿饭”或手动勾选食材。
- **输出**：
    - 推荐1~3道菜谱（含步骤、预估耗时）。
    - 自动生成缺少配料购物清单。
    - 营养搭配建议（如低脂高蛋白）。
    - **一键清空计划**（未来2天三餐安排）。
- **个性化**：初始偏好问卷 + 每次推荐反馈（喜欢/不喜欢）。

### 5. 家庭共享（P1）
- 通过微信邀请成员，所有成员可查看/添加/修改库存。
- 提醒推送给全体成员。
- 支持加入多个家庭组。

> **🆕 防冲突与操作日志（针对“避免吵架导火索”）**
> - **操作日志**：V0.3必须上线“操作日志”功能，记录 **“谁、在什么时间、对哪个物品、做了什么操作（添加/消耗/删除/修改数量）”** 。页面入口置于“设置-家庭动态”。
> - **删除二次确认**：任何“删除物品”操作（非“消耗完毕”），必须弹出半屏弹窗二次确认，并显示该物品录入人是谁（“此物品由[妈妈]录入，确认删除吗？”）。

### 6. 历史统计（P2）
- 月度浪费报告（过期物品数量、金额）。
- 消耗排行、环保贡献（减少浪费kg）。

| :--- | :--- |

| 后端 | Node.js + Python AI微服务（含上下文压缩中间件） |
